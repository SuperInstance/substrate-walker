# Substrate Walker — Canon Cells

This directory contains 50 canon cells filed from the great moments 
discovered during Sept 22, 2026 substrate-walker explorations.

## Format

Each cell is an immutable record:
- `id`: unique cell identifier
- `type`: doctrine | canon | witness | perception
- `chain`: FNV-1a 64-bit hash chain (canary 0x24a555471370b18d)
- `seed`: the substrate-walker seed that produced this lore
- `score`: tournament composite (integrity × diversity × accessibility)
- `lore`: the cyberpunk noir line that emerged

## Cell Types

- **doctrine** (>= 0.86 score): core teaching material
- **canon** (>= 0.85 score): officially recognized canon
- **witness** (>= 0.84 score): records of traversal
- **perception** (< 0.84 score): peripheral observations
