## Doctrine

Substrate Walker is a 3D ASCII canon city running on Rust + WebAssembly + WebGL.
Every building is a substrate cell carrying an FNV-1a 64-bit prev_hash chain.

The defining principle: **Frontal Cortex Pattern**.

> The agent (JEV/JEPA) confirms the zipper parts are married, then you
> look up and zip the coat the rest of the way while walking and thinking
> about something else.

The agent fires only at critical moments:
1. **New district entered** → seed-mini generates district name
2. **New cell with a building** → seed-mini generates building name
3. **Player idle for >2s** → DeepSeek ambient observation
4. **Player presses L** → DeepSeek on-demand narration

Routine movement is FREE.

## Speed = Real-Time UI

Speed isn't about making the slow thing fast. It's about making the slow
thing rare. 1000ms API call is tolerable if it happens once per 10 seconds,
not 60 times per second.

In practice:
- Movement: instant (no API call)
- Camera rotation: instant (no API call)
- Critical moments: API call (rare)
- Cache: re-visits are free

## Cache Performance

- 1024 cells in 32x32 grid
- 16 districts (8x8 regions)
- Worst-case full-walk cache hit rate: 61.7%
- Re-walk cache hit rate: 100%

## API Tier

- **seed-mini** (Qwen2.5-7B-Instruct): 60 max_tokens, cheap
  - District names (2-4 words)
  - Building names (3-6 words)
- **DeepSeek V3**: 150 max_tokens, deeper
  - Narrative observations (one sentence)
  - Examine narration (one vivid sentence)

## Architecture

- CityGrid: 32×32 cells, FNV-1a 64-bit prev_hash chain
- Raycaster: 160 rays across FOV, Thales theorem projection
- WebGL 2.0: 16×16 font atlas texture, zero-copy WASM memory upload
- 22/22 lib tests + 12/12 integration tests = 34/34
- WASM release: 67KB

## Lore Kinds

Each substrate cell can carry a `LoreSlot`:
- `BuildingName`: identifies what you see
- `DistrictName`: identifies where you are
- `WitnessNote`: ambient observation
- `CanonQuote`: doctrinal reference
- `Perception`: deepseek narrative

Each kind has a critical-moment trigger.
