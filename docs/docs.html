Cyberpunk ASCII City

A 3D ASCII cyberpunk city rendered in the browser using Rust + WebAssembly + WebGL. Every building is a substrate cell from the Quilt canon, carrying an FNV-1a 64-bit prev_hash chain.

Architecture

  ┌─────────────────────────────────────────────┐
  │              Rust Core (WASM)               │
  │                                             │
  │  [CityGrid (32×32 cells)]                   │
  │         ↓                                   │
  │  [Raycaster::cast(camera, grid)]            │
  │         ↓                                   │
  │  [Vec<PackedCell> of 160×60 cells]            │
  │         ↓                                   │
  │  [Zero-copy WASM memory buffer]             │
  └─────────────────────────────────────────────┘
                        ↓ (raw memory read)
  ┌─────────────────────────────────────────────┐
  │              Browser (WebGL 2.0)            │
  │                                             │
  │  [JS reads Uint8Array from WASM heap]       │
  │         ↓                                   │
  │  [texImage2D → texture slot 0]              │
  │         ↓                                   │
  │  [Fragment shader → font atlas → screen]    │
  └─────────────────────────────────────────────┘

Substrate Cells

Each cell in the city grid carries:

  • x, y: position
  • height: building height (0 = empty street)
  • cell_type: 0=doctrine, 1=witness, 2=canon, 3=perception
  • prev_hash: FNV-1a 64-bit hash of previous cell
  • hash: FNV-1a 64-bit hash of self + prev_hash

The chain integrity is verified across all 1024 cells (32×32 grid). Tampering with any cell breaks the chain.

Raycasting

Each frame, the raycaster casts 160 rays across the FOV. Each ray steps through the grid in DDA style until it hits a building. The distance determines the column's projection height via Thales' theorem: 

        h(u) = H / D(u) × sec(θ)

Where H is the screen height, D(u) is the ray's distance to the building, and sec(θ) is the fish-eye correction factor.

Color Encoding

Each packed cell is a 32-bit word with this layout: 

    bits  0..7   → ASCII glyph (u8)
    bits  8..15  → Red channel
    bits 16..23  → Green channel
    bits 24..31  → Alpha (luminance/depth)

The fragment shader decodes the glyph index and samples a 16×16 font atlas texture. The cell's color is multiplied by the glyph mask.

Build

cargo build --release --target wasm32-unknown-unknown --features wasm
cp target/wasm32-unknown-unknown/release/cyberpunk_ascii_city.wasm web/city.wasm

Controls

  • W / ↑: walk forward
  • S / ↓: walk backward
  • A / ←: turn left
  • D / →: turn right
  • Q / E: alternative turn
  • R: reset to (16, 16) facing east
  • P: capture PNG

Fleet Canary

The FNV-1a 64-bit canary for "café Δ 日本語" is 0x24a555471370b18d, verified across all SuperInstance substrate-aware repos.
